# v0.1.0

First public release. Range: the repository's root commit.

The history before this point was squashed away, so there is no previous
tag to diff against and nothing here reads as a list of changes. What the
release *contains* is the whole feature set, which `../CHANGELOG.md`
describes by area.

In short: git hosting served straight out of S3-compatible object storage,
over `ssh://` and git smart-HTTP, with a read-only web browsing UI — one
binary, no separate git daemon. Everything uploaded to the bucket is
encrypted (XChaCha20Poly1305), mandatory and with no opt-out. Includes
accounts, groups and per-repo permissions, pull requests, releases with
assets, Git LFS, cross-repo search, and an admin UI.
